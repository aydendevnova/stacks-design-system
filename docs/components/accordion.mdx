## API Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `type` | `"single" \| "multiple"` | — | Whether one or multiple items can be opened at once |
| `defaultValue` | `string \| string[]` | — | The value(s) of the item(s) to expand by default |
| `collapsible` | `boolean` | `false` | When `type` is `"single"`, allows closing all items |
| `value` | `string \| string[]` | — | Controlled expanded value(s) |
| `onValueChange` | `function` | — | Callback when the expanded state changes |

## Accessibility

The Accordion component follows WAI-ARIA accordion patterns:

- Uses appropriate ARIA roles (`region`, `heading`, `button`)
- Supports keyboard navigation (Arrow keys to move between triggers, Enter/Space to toggle)
- Includes proper `aria-expanded` and `aria-controls` attributes
- Content regions are properly labeled by their triggers
