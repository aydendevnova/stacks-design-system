## API Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | — | Controlled open state |
| `defaultOpen` | `boolean` | `false` | Initial open state for uncontrolled usage |
| `onOpenChange` | `(open: boolean) => void` | — | Callback when open state changes |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Preferred side of the trigger to render |
| `align` | `"start" \| "center" \| "end"` | `"center"` | Preferred alignment against the trigger |
| `sideOffset` | `number` | `4` | Distance from the trigger in pixels |

## Accessibility

The Popover component follows WAI-ARIA popover patterns:

- Focus is moved into the popover when opened
- Escape key closes the popover
- Click outside closes the popover
- Focus returns to trigger when closed
