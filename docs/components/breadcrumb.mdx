## API Reference

### Breadcrumb

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `separator` | `ReactNode` | — | Custom separator element |
| `children` | `ReactNode` | — | BreadcrumbList and its children |

### BreadcrumbLink

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `href` | `string` | — | The URL the breadcrumb links to |
| `asChild` | `boolean` | `false` | Render as child element instead of anchor |

### BreadcrumbPage

Renders the current page label. Styled with primary color and `aria-current="page"`.

### BreadcrumbSeparator

Renders a separator between breadcrumb items. Defaults to a `ChevronRight` icon. Pass children to customize.

### BreadcrumbEllipsis

Renders a `MoreHorizontal` icon to indicate collapsed items.

## Accessibility

The Breadcrumb component follows WAI-ARIA breadcrumb patterns:

- Uses `<nav>` with `aria-label="breadcrumb"` for landmark navigation
- Current page is marked with `aria-current="page"` and `aria-disabled="true"`
- Separators are hidden from assistive technology with `aria-hidden="true"`
- Uses an ordered list (`<ol>`) to convey hierarchy to screen readers
